# Data Sources Tracker and Schema Reference

This document tracks every open-source and partner dataset supported by `wild-fish-zeroshot-clustering`, its exact disk layout under `data/raw/`, its wild-only filtering rules, and how it maps into the unified manifest CSV schema.

> **Git Safety Policy:** All raw images, downloaded archives (`data/raw/*`), processed crops (`data/processed/*`), and generated manifest CSVs (`data/manifests/*.csv`) are excluded in [`.gitignore`](../.gitignore) and remain local only. Only code, configs, download scripts, and documentation are pushed to GitHub.

---

## 1. Unified Manifest Schema

Every dataset builder in [`src/fish_clustering/data/manifest.py`](../src/fish_clustering/data/manifest.py) normalizes heterogeneous directory layouts, CSVs, and YOLO bounding boxes into a single 16-column CSV schema (`MANIFEST_COLUMNS`) generated by [`scripts/build_manifests.py`](../scripts/build_manifests.py):

| Column | Type | Description |
| :--- | :--- | :--- |
| `image_id` | `str` | Unique sample identifier prefixed by dataset (e.g. `frgt_00420000101_00001`, `ozfish_1`, `med_train_...`) |
| `dataset` | `str` | Canonical dataset key (`frgt`, `ozfish`, `fishwio`, `mediterranean`, `fjordfish_wild`, `brackish`, `deepfish`, `hodor`, `schufi`) |
| `source_type` | `str` | `"wild"` for underwater field datasets; `"controlled"` for lab/trawl subsets such as `schufi` if studio frames are present |
| `image_path` | `str` | POSIX path relative to `data.raw_root` (e.g. `frgt/extracted/fish/...`) |
| `mask_path` | `str` | Relative path to binary foreground mask PNG (`frgt`), blank otherwise |
| `bbox_x1`, `bbox_y1`, `bbox_x2`, `bbox_y2` | `float` | Pixel-coordinate bounding box when source is an uncropped frame (`mediterranean`, `brackish`), empty for pre-cropped fish |
| `label_raw` | `str` | Original dataset label (`cluster_1`, folder name, YOLO class, habitat, or coarse tag) |
| `family`, `genus` | `str` | Parsed taxonomic family and genus when provided or inferred from folder/class strings |
| `species` | `str` | Standardized Latin binomial (`Genus species`, lowercase epithet) when species-level ID is valid, else empty |
| `is_species_level` | `bool` | `True` only for valid Latin binomial species labels (excludes `sp-`, `unid-`, `small`, `cluster_*`, `fish`) |
| `video_id` | `str` | Sequence/camera clip ID used by `cap_crops_per_video` to curb consecutive-frame duplicates |
| `split` | `str` | Original dataset split (`train`, `valid`/`val`, `test`) when present |

All manifest scanners automatically skip hidden files and macOS AppleDouble metadata entries (`name.startswith(".")` such as `._*.jpeg`).

## 3. Per-Dataset Acquisition & Parsing Notes

### 3.1 `frgt` (Fish4Knowledge Ground Truth)
- **Download:** Automated via `python scripts/download_datasets.py --dataset frgt`.
- **Expected local layout:**
  - `data/raw/frgt/class_id.csv` (`file_name,cluster_id`)
  - `data/raw/frgt/extracted/fish/fish_XX/*.png`
  - `data/raw/frgt/extracted/mask/mask_XX/mask_*.png`
- **Parsing details:** `class_id.csv` uses 11-digit unpadded IDs (e.g. `00420000101_00001`) while extracted images on disk have 12-digit zero-padded names prefixed with `fish_` or `mask_` (`fish_000420000101_00001.png`). `_normalize_frgt_key` strips prefixes and leading zeros so all `27,370` images match their binary foreground mask 1-to-1.
- **Labeling note:** `cluster_id` represents cluster/class indices without standardized Latin binomials (`is_species_level=False`, `label_raw="cluster_<id>"`).

### 3.2 `ozfish` (AIMS Baited Remote Underwater Video Stations)
- **Download:** Manual instructions printed by `python scripts/download_datasets.py --dataset ozfish`.
- **Expected local layout:** `data/raw/ozfish/metadata/crop_metadata.csv` and `data/raw/ozfish/crops/*.png`.
- **Parsing details:** Reads `(uid, file_name, family, genus, species)`. Marks `is_species_level=True` only when both `genus` and alphabetical species epithet are valid. Strips stereo suffixes `_L` / `_R` (`A000001_L.avi...` -> `video_id="A000001"`) so paired stereo views of the same frame count toward one video group under `max_crops_per_video`.

### 3.3 `fishwio` (Western Indian Ocean Reef Crops)
- **Download:** Automated via `python scripts/download_datasets.py --dataset fishwio`.
- **Expected local layout:** `data/raw/fishwio/extracted/data_paper_dataset/<ClassFolder>/*.jpeg`.
- **Parsing details:**
  - Folders beginning with `_` (`_calcareous`, `_coral_hard`, `_coral_soft`, `_dark`, `_macroalgae`, `_sand`, `_water_blue`, `_water_surface`) are background/habitat classes and are excluded from fish clustering manifests.
  - Stage/morph suffixes (`_juvenile`, `_adu`, `_adult`, `_female`, `_male`, `_initial`, `_terminal`, `_phase`) are stripped before extracting the Latin binomial (`Genus species`) into `species`, while `label_raw` preserves the full folder name.
  - Extracts `video_id` prefix before the clip hash/coordinate tail (`<video_or_site>_<hash>_<frame>_<w>x<h>`) so burst frames from one sequence can be capped cleanly.

### 3.4 `mediterranean` (DeepEcoMar YOLO Dataset)
- **Download:** Automated via `python scripts/download_datasets.py --dataset mediterranean`.
- **Expected local layout:** `data/raw/mediterranean/extracted/DEEPECOMAR_DATASET_YOLO/{data.yaml,train/{images,labels},valid/{images,labels}}`.
- **Parsing details:** Converts YOLO normalized `(cx, cy, w, h)` labels into pixel `(bbox_x1, bbox_y1, bbox_x2, bbox_y2)` per detection box (multiple boxes per frame produce distinct rows). Filters ambiguous classes (`Diplodus sp-`, `Mullus sp-`, `Sphyraena sp-`, `Symphodus sp-`, `labrid unid-`, `Mugilidae prob Chelon`, `Afish poly`, `small`, `taca`) to `is_species_level=False` while keeping true binomials (`Chromis chromis`, `Coris julis`, `Diplodus vulgaris`, `Sarpa salpa`, etc.) as `is_species_level=True`.

### 3.5 `fjordfish_wild` (Scandinavian Coastal Fjords)
- **Download:** Automated via `python scripts/download_datasets.py --dataset fjordfish`.
- **Wild-only control:** When organizing extracted folders into `data/raw/fjordfish_wild/` (or `data/raw/fjordfish/`), exclude the IMR Flodevigen mesocosm cod frames so the dataset remains strictly wild RUV imagery matching our literature-survey scope.

### 3.6 `brackish` (Limfjorden Brackish Dataset)
- **Download:** Automated via `python scripts/download_datasets.py --dataset brackish` (requires Kaggle CLI token at `~/.kaggle/kaggle.json`).
- **Expected local layout:** `data/raw/brackish/extracted/annotations/annotations_AAU/{train,valid,test}.csv` and `data/raw/brackish/extracted/frames/*.png`.
- **Parsing details:** Reads semicolon-delimited `;` AAU annotation CSVs, retains only fish tags (`Annotation tag` in `{"fish", "small_fish"}`, dropping `crab`, `starfish`, `jellyfish`, and `shrimp`), extracts pixel bounding boxes, and parses clip `video_id`.

### 3.7 `deepfish` (Tropical Australian Habitats)
- **Download:** Manual clone/fetch from [alzayats/DeepFish](https://github.com/alzayats/DeepFish).
- **Expected local layout:** `data/raw/deepfish/extracted/DeepFish/Classification/{train,val,test}.csv` and image subdirectories (`<ID>.jpg`).
- **Parsing details:** Filters `labels == 1` to retain fish-present frames (`labels == 0` empty background frames are excluded) with `label_raw="habitat_<id>"` and `is_species_level=False`.

### 3.8 `hodor` & `schufi` (Baltic Sea Target Datasets)
- **`hodor`:** Use `hodor-python` against PANGAEA `10.1594/PANGAEA.980000` to pull only fish-active underwater sequences into `data/raw/hodor/`.
- **`schufi`:** Place University of Rostock / SCHUFI Baltic Sea monitoring frames under `data/raw/schufi/`. For unboxed full frames, [`scripts/crop_schufi_frames.py`](../scripts/crop_schufi_frames.py) will run automated fish detection (`grounding_dino` or `fishdet_m`, configured under `cropping:` in YAML) once detector choice is finalized with supervisors.

## 4. Intentionally Excluded Datasets

- **`FishDet-M`:** Excluded from unsupervised fish clustering because it mixes wild underwater datasets with aquarium tank photos and web-scraped `FishNet` imagery and collapses labels to a single `'fish'` class. Its detector comparisons inform cropping only.
- **`f4k_subset`:** Excluded as a smaller subset redundant with full `frgt`.
- **Freshwater / Lab Aquaculture Sets (e.g., Jansen et al. 2022):** Excluded to maintain strict marine and brackish wild fish scope across RQ1 and RQ2.

## 5. Checklist for Adding a New Dataset

1. Add a `DatasetSpec` entry in [`scripts/download_datasets.py`](../scripts/download_datasets.py) and document it here and in [`data/raw/README.md`](../data/raw/README.md).
2. Implement `build_<name>_manifest(raw_root: Path) -> pd.DataFrame` returning `MANIFEST_COLUMNS` in [`src/fish_clustering/data/manifest.py`](../src/fish_clustering/data/manifest.py) (skipping dotfiles starting with `"."`) and register it in `DATASET_BUILDERS`.
3. Add a synthetic fixture unit test in [`tests/test_data.py`](../tests/test_data.py) and verify with `pytest -v`.
4. Add `<name>` to the target experiment YAML file under `configs/` and run `python scripts/build_manifests.py --config configs/<file>.yaml`.
